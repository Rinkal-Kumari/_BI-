# 📊 Digital Sales Performance Dashboard

This repository contains a Power BI dashboard designed to analyze and visualize digital product sales across multiple platforms, channels, and customer segments.

## 🚀 Project Overview

The **Digital Sales Performance Dashboard** helps businesses and analysts:
- Monitor key sales KPIs (revenue, quantity, average price, etc.)
- Understand customer demographics and buying behavior
- Evaluate product and platform performance
- Identify high-performing marketing channels
- Track customer satisfaction using NPS scores

## 🧩 Dashboard Features

### ✅ Key Metrics
- Total Revenue: `757K`
- Quantity Sold: `9K`
- Average Price: `$84.52`
- Unique Customers: `3K`
- Average NPS Score: `5.10`

### 📈 Visuals Included
- **Revenue Trends** by Date and Product Category
- **Top-Selling Products** by Revenue and Quantity (Treemap)
- **Revenue by Marketing Channel** with % Contribution
- **Top Customer Countries**
- **NPS Score Distribution** (Promoters, Passives, Detractors)
- **Platform-wise Sales Distribution**
- Interactive filters for:
  - Year/Month/Week
  - Marketing Channel
  - Gender
  - Platform

## 🛠 Tools & Technologies
- **Power BI**
- **DAX** (Data Analysis Expressions)
- **Data Cleaning & Modeling**
- CSV & Excel data sources (not included here for privacy)
